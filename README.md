# 내 세금 영수증

연봉을 넣으면 내가 1년에 내는 세금(근로소득세·지방소득세·부가세)을 어림하고, 그 세금이 2026년 정부 예산 12대 분야와 보조금 단체(예: 대한축구협회)로 얼마씩 가는지 보여주는 정적 웹페이지입니다.

## 실행

빌드 과정이 없습니다. ES 모듈을 쓰므로 `index.html` 을 파일로 직접 열지 말고 정적 서버로 엽니다.

```sh
npm start     # npx serve .
npm test      # node --test
```

## 구조

| 경로 | 역할 |
| --- | --- |
| `index.html` | 화면 마크업과 스타일 |
| `src/app.js` | 입력을 읽어 결과를 그리는 화면 코드 |
| `src/tax.js` | 세금 계산 순수 함수 (DOM 없음) |
| `data/tax-rules-2026.js` | 세율·공제·보험료율 |
| `data/budget-2026.js` | 12대 분야 예산과 하위 항목(출처 포함) |
| `test/` | 계산·데이터 테스트 |

## 데이터 출처

- 12대 분야 재원배분: 국회예산정책처, 「2026년도 예산안 분야별 재원 배분 분석」(2025.10, 정부안 728.0조 원)
- 2026년 확정 총지출 727.9조 원: 정책브리핑, 「728조 규모 2026년 예산 국회 통과」
- 대한축구협회 정부 보조금: 머니투데이, 「매년 300억 어디다 썼나」(2026.6)

## 계산의 한계

- 근로소득세는 세율 구간·근로소득공제·기본공제·근로소득세액공제·표준세액공제만 반영한 어림값입니다. 연말정산 특별공제는 빠져 있습니다.
- 4대보험 요율은 근삿값이며 상한액을 반영하지 않습니다.
- 부가세는 실수령액 중 소비 비율 × 과세 품목 60% × 1/11 로 어림합니다.
- 국세는 정부 총지출과 같은 비율로 쓰인다고 가정합니다.

## 단체·사업 추가

`data/budget-2026.js` 에서 해당 분야의 `items` 에 `{ name, won, desc, basis, source: { label, url } }` 를 추가합니다. `basis` 는 `공식 자료` 또는 `보도 기준` 처럼 근거 종류를 적습니다. 출처 없는 금액은 넣지 않으며, `npm test` 가 출처 누락을 잡습니다.
